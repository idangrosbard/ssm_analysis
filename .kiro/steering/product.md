# Product Overview

## Purpose

Research project for analyzing Mamba State-Space Models using knockout methodology to understand factual information flow in language models.

## Core Functionality

- **Knockout Analysis**: Adapts attention knockout methodology from Transformers to Mamba-1 and Mamba-2 models
- **Information Flow Tracing**: Tracks how factual information is transmitted and localized across tokens and layers
- **Model Comparison**: Analyzes patterns across different architectures (Mamba, GPT-2, Llama, Mistral, Qwen)
- **Feature Disentanglement**: Leverages Mamba's structured factorization to understand token-to-token information exchange

## Key Research Contributions

- Theoretical and empirical connections between Mamba SSMs and Transformer attention mechanisms
- Subject-token information emergence patterns and layer-wise dynamics analysis
- Universal vs model-specific phenomena identification across language model architectures
- Unified lens for understanding Mamba internal operations through feature analysis

## Target Users

- Machine learning researchers studying state-space models
- Scientists investigating interpretability in language models
- Developers working on factual information flow analysis
- Academic researchers in natural language processing

## Output Artifacts

- Research paper accepted at ACL 2025
- Reproducible experimental framework
- Interactive Streamlit web interface for analysis
- Comprehensive plotting and visualization tools
- Experimental results and analysis data
